# Лендинг школы английского языка — Bostandyk School

- **Тема:** Школа английского языка (курсы, преподаватели, бесплатный пробный урок).
- **Живой сайт:** https://<botacorre>.github.io/landing-bostandyk/

## Что сделано:
1. Выполнена семантическая разметка HTML5: `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`.
2. Реализовано 4 блока: шапка с меню, «о нас», программы курсов, форма заявки на пробный урок.
3. Добавлена форма обратной связи с обязательными полями (`required`) и связанными тегами `<label>`.
4. Соблюдена иерархия заголовков `h1 → h2 → h3` и добавлен атрибут `alt` для картинок.
5. Заполнены мета-теги SEO в `<head>` (`title`, `description`, `viewport`, `favicon`).
6. Верстка адаптирована под экраны от 375px до 1280px.
