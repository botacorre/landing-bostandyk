## Почему этот инструмент (Sass + BEM)

Использование препроцессора Sass вместе с методологией BEM позволило сделать структуру стилей гибкой и поддерживаемой. С помощью файла `_variables.scss` все основные цвета и параметры сайта вынесены в одно место, что существенно упрощает их изменение. Миксин `respond-to` дал возможность удобно управлять медиазапросами без постоянного дублирования правил `@media`. Методология BEM (`block__element--modifier`) полностью исключает конфликты имён классов и делает CSS понятным. Главное ограничение Sass — необходимость компиляции в чистый CSS для работы на GitHub Pages. По сравнению с Tailwind и Bootstrap, данный подход не перегружает HTML-разметку служебными классами и даёт полный контроль над итоговым CSS-кодом.
